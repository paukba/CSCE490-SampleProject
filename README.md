# CSCE490-SampleProject

Sample Project for CSCE 490 - Research Milestone

This project is a simplified version of what my group's final project, a research content management system. It is a web application in which users are able to browse research projects, search and filter projects, view additional project information, and manage research project entries.

## Important Technologies Learned About and Involved in this Project:
- JavaScript
- Node.js
- React
- Express
- Vite
- HTML and CSS
- npm
- Express

## Running the Application:
    1. Install Node.js and npm.
    2. Clone this GitHub repository.
    3. Open the project folder in a terminal.
    4. Install dependencies:
       npm install
    6. Start the development server:
       npm run dev
    Open the local URL displayed in the terminal, typically http://localhost:5173/.
